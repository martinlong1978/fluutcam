# Bundled UI font

`NotoSans-Regular.ttf` is Noto Sans Regular (unhinted TTF) from the Noto project,
<https://github.com/notofonts/latin-greek-cyrillic>, as published in
<https://github.com/notofonts/notofonts.github.io> (`fonts/NotoSans/unhinted/ttf/`).

It is licensed under the SIL Open Font License, Version 1.1; the licence text is in
[`OFL.txt`](OFL.txt). FluutCAM embeds the file unchanged in the `fluutcam` binary
(D13 §6, spec 08 §8.9). It is the only font the UI loads: `egui`'s `default_fonts` are off.
