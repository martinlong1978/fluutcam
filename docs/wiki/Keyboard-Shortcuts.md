# Keyboard shortcuts

On macOS, use **Cmd** where this page says **Ctrl**.

## Project

| Keys | Same as the ribbon button |
|---|---|
| **Ctrl+N** | New project |
| **Ctrl+O** | Open |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save as |
| **Ctrl+I** | Import model |
| **Ctrl+Z** | Undo |
| **Ctrl+Y** or **Ctrl+Shift+Z** | Redo |

- The shortcuts that open a file dialog do nothing while a dialog is already open.
- Save, Save as and Import need an open project.
- While you type in a text box, **Ctrl+Z** and **Ctrl+Y** are left to the text box: they undo and redo the typing, not the project.
- A shortcut does nothing when its button is greyed out.

## Viewport

| Mouse | Result |
|---|---|
| Drag | Orbit |
| Right or middle drag | Pan |
| Wheel | Zoom |
| Click | Pick the face or toolpath under the pointer. In pick mode: add or remove the face or curve |
| Double-click | Zoom to fit |

## Browser and pick mode

| Key | Result |
|---|---|
| **F2** | Rename the selected Setup or toolpath |
| **Del** | Delete the selected Setup or toolpath (undo brings it back) |
| **Esc** | In pick mode: leave it. While renaming: cancel the rename |

F2 and Del do nothing while you type in a box, while you rename, or in pick mode. Click a row of the Browser first, so the selection is the one you mean.

## Menus and boxes

| Key | Result |
|---|---|
| **Esc** | Closes an open list |
| **Enter** | In a number box in the inspector: applies the value |

The title bar's unit badge has no shortcut. There are no other shortcuts yet, and you cannot change them. The ribbon buttons show their shortcut in their tooltips.
